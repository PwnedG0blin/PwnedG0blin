# ClipShift 0.2.0 Beta 1 — Liquid Glass DMG

## Deutsch

ClipShift wandelt neue macOS-Bildschirmaufnahmen auf dem Schreibtisch automatisch von MOV in MP4 um. Die App verwaltet eine native macOS-Ordneraktion und benötigt **FFmpeg**.

**Neu in dieser Beta**
- Eigenständige ClipShift.app mit deutscher und englischer Oberfläche.
- Genau zwei Hauptaktionen: **Installieren** / **Deinstallieren**.
- Dunkelblaues Liquid-Glass-Design für das DMG-Fenster.
- Eigenes ClipShift-App-Icon, passend zur Website-Grafik.
- App per Drag & Drop in den Programme-Ordner ziehen.
- MOV-Originale bleiben standardmäßig erhalten; bestehende Löschoption einer früheren Installation wird übernommen.

**Voraussetzungen:** macOS 13+ auf Apple Silicon, FFmpeg und FFprobe (z. B. `brew install ffmpeg`). Die native Glasoptik ist von der macOS-Version abhängig.

**Bitte beachten:** Dies ist eine öffentliche **Testversion**. Die App ist ad-hoc-signiert und **nicht notarisiert**. macOS Gatekeeper und Browser können deshalb warnen. Eine erfolgreiche GitHub-Build-Prüfung ist kein umfassender Sicherheitstest. Vor der breiten Verwendung die Installation und Deinstallation mit einer kurzen Testaufnahme prüfen. Ein gültiges Apple Developer ID-Zertifikat und anschließende Notarisierung sind für eine reguläre, vertrauenswürdig signierte Verteilung vorgesehen.

## English

ClipShift automatically converts newly created MOV screen recordings on the macOS Desktop to MP4 with a native Folder Action and **FFmpeg**.

**What's new**
- Standalone bilingual ClipShift.app.
- Two primary actions: **Install** / **Uninstall**.
- Custom dark-blue Liquid Glass DMG window and app icon.
- Drag-to-Applications installation.
- Source recordings are preserved by default; the previous delete-after-success preference is respected.

**Requirements:** macOS 13+ on Apple Silicon, FFmpeg and FFprobe (`brew install ffmpeg`).

**Security and testing:** Public **beta**, ad-hoc signed, **not notarized**. Gatekeeper and browser warnings may appear. A successful CI build does not confirm a full safety or installation test. Test carefully before daily use; Apple Developer ID signing and notarization are still outstanding.
