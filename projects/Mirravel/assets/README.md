# Mirravel app icon

`MirrorGlass.png` is the selected Mirror Glass artwork for Mirravel. It was created with image generation and selected by PwnedG0blin on 28 October 2026.

The transparent PNG is the source asset. The macOS build script generates all standard icon sizes with sips, creates Mirravel.icns with iconutil, sets CFBundleIconFile, then signs the complete app bundle. The same signed Mirravel.app is included in the App ZIP and DMG.
